# Privacy Policy

This plugin connects to your self-hosted Ansible AWX / Ansible Tower instance using credentials you provide.

- **No data is sent to third parties.** All API calls are made directly from the Dify server to the AWX instance you configure.
- **Credentials** (AWX URL and API Token) are stored encrypted in Dify's secret store and are never transmitted outside your infrastructure.
- **Indexed content** (job templates, workflow templates, job history) is stored only in your Dify knowledge base.

This plugin does not collect, share, or store any data externally.
